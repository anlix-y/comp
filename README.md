# Video & Image Compressor Service

Удобный веб-инструмент для скачивания, сжатия и конвертации видео и изображений. Позволяет обрабатывать локальные файлы или скачивать видео напрямую по ссылке (YouTube и другие поддерживаемые платформы).

## Основные возможности

### Видео
*   **Сжатие видео**: Уменьшение размера файла с настройкой CRF, разрешения и FPS.
*   **Конвертация в GIF**: Создание анимированных GIF из видеофрагментов.
*   **Извлечение аудио**: Конвертация видео в формат MP3 (128k).
*   **Загрузка по ссылке**: Прямая интеграция с `yt-dlp` для скачивания видео перед обработкой.

### Изображения
*   **Сжатие изображений**: Поддержка форматов JPG, PNG и WebP.
*   **Изменение размера**: Возможность ограничения максимальной ширины изображения с сохранением пропорций.

## Технологический стек
*   **Backend**: Go (Gin Gonic)
*   **Обработка мультимедиа**: FFmpeg
*   **Загрузка видео**: yt-dlp (с автоматическим обновлением при старте)
*   **Очередь задач и состояние**: Redis
*   **Контейнеризация**: Docker + Docker Compose
*   **Хранилище**: Временная файловая система (tmpfs) для быстрой обработки данных.

## Быстрый запуск

Для запуска приложения вам потребуется [Docker](https://docs.docker.com/get-docker/) и [Docker Compose](https://docs.docker.com/compose/install/).

1.  Клонируйте репозиторий:
    ```bash
    git clone <repository_url>
    cd comp
    ```

2.  Запустите сервисы:
    ```bash
    docker-compose up -d --build
    ```

3.  Откройте приложение в браузере:
    [http://localhost:3000](http://localhost:3000)

## Конфигурация

Настройки приложения находятся в файле `web/config.json`:

```json
{
  "cleanup_minutes": 60,
  "port": 3000
}
```

*   `cleanup_minutes`: Время жизни обработанных файлов в минутах. После этого времени временные директории заданий будут автоматически удалены.
*   `port`: Порт, на котором будет запущено приложение (внутри контейнера).

## Использование

1.  **Выбор источника**: Выберите локальный файл на вашем компьютере или вставьте ссылку на видео (например, с YouTube).
2.  **Настройка параметров**:
    *   **CRF (для видео)**: Коэффициент постоянного качества (обычно 18-28). Чем выше значение, тем сильнее сжатие и ниже качество.
    *   **Ширина (Width)**: Желаемая ширина выходного видео или изображения.
    *   **FPS (для видео/GIF)**: Количество кадров в секунду.
    *   **Качество (для изображений)**: Значение от 1 до 100.
3.  **Запуск**: Нажмите кнопку обработки и дождитесь завершения. Прогресс будет отображаться в реальном времени.
4.  **Скачивание**: По завершении обработки появится ссылка на скачивание готового файла.

## Особенности реализации

*   **Автоматическое обновление yt-dlp**: При каждом запуске контейнера приложение проверяет наличие новой версии `yt-dlp` и обновляет её для стабильной работы с YouTube.
*   **Tmpfs**: Обработка файлов происходит в `/tmp/app`, которая в Docker Compose настроена как `tmpfs` объемом 2 ГБ. Это ускоряет работу и бережет ресурс диска.
*   **Redis**: Используется для хранения статусов задач и прогресса, что позволяет отслеживать выполнение длительных операций.
